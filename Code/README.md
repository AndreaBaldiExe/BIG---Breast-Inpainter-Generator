This is the ultimate code folder.
It contains 2 files:
- built_init_data.py: it's executed locally to preprocess data. We used [![Kaggle](https://img.shields.io/badge/Kaggle-035a7d?style=for-the-badge&logo=kaggle&logoColor=white)](https://www.kaggle.com/datasets/shantanughosh/vindr-mammogram-dataset-dicom-to-png) which is the dicom to png version of VinDR Mammogram. This script parses data by lesion classes, reshaping bboxes and annotations.
- BIG.py: it is the python version of notebook project. The interactive notebook is available in Report folder.

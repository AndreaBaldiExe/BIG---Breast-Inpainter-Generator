This is the ultimate code folder.

- built_init_data.py: it's executed locally to preprocess data. This script parse data by lesion classes, reshape bboxes and annotations.
- BIG.py: it is the python version of notebok project. The interactive notebook is available here: [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1jEK0JIGETpPRvjo7vMaf-Ix4AsdFmWB4?usp=sharing)

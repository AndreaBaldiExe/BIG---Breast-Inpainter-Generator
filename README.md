# BIG---Breast-Inpainter-Generator
BIG is a mammogram inpainter which can either generate from pure noise or transfer already-existing lesions (Masses and Suspicious Calcifications) on healthy patients.

This projects aims to be a useful tool in Clinical Field, it might be used to generate new realistic and clinical-consistent mammograms enhancing research. New models training may use images generated by BIG to create new dataset, easily choosing lesion's type, position and other clinical values.
